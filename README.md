## 💡 What is Memora?

**Project Memora** is a Flutter-based mobile app designed for individuals with memory challenges, offering a **voice-powered, accessible interface** to manage daily reminders and key information.  
Built with empathy and scalability in mind, Memora supports **text-to-speech feedback**, **simple UI**, and **secure data separation** for multiple users.

---

## 🚀 Key Features

| Feature | Description |
|--------|-------------|
| 🎙 **Voice Command Input** | Say _"Add an item"_ to trigger the voice flow. Built using `speech_to_text` |
| 🗣 **Text-to-Speech Feedback** | Instant audio responses powered by `flutter_tts` |
| 🧾 **Accessible UI** | Big buttons, high contrast — built for real-world accessibility |
| 👤 **Scoped User Sessions** | Each user only sees their data — nothing gets mixed |
| 🔒 **Secure Item Access** | Local/session-based isolation for privacy and focus |
| 💬 **Natural Language Intent** *(Coming Soon)* | Understand commands like _“Remind me to take medicine at 5 PM”_ |

## 🧠 How it Works

### Voice Flow
1. User taps mic icon or says “Add item”
2. App listens via `speech_to_text`
3. App prompts with questions (e.g., item name, category)
4. Data is stored & confirmed using `flutter_tts` audio response
